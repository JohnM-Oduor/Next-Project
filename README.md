
# Next-Project

This is a Next.js project built using React and Tailwind CSS.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
